# Lecture 01 – Introduction to Website Designing and HTML

## 1. Introduction to Website Designing

Website Designing is the process of planning, structuring, and creating the visual appearance and layout of websites.

It focuses on how information is presented to users and how users interact with different elements of a website.

A website can contain different types of information, such as:

- Text and headings
- Images and videos
- Audio files
- Links and navigation menus
- Forms and buttons
- Tables and other data

### What is a Website?

A website is a collection of related web pages that are generally available under a common domain name and can be accessed through the World Wide Web.

For example:
- https://www.google.com
- https://www.wikipedia.org
- https://www.aptech-education.com.pk

A website may contain multiple web pages connected through hyperlinks.

### What is a Web Page?

A web page is an individual document available on the World Wide Web.

For example, a website may contain:

- Home Page
- About Us Page
- Services Page
- Contact Us Page

All these pages can be part of a single website.

**Website vs Web Page**

| Website | Web Page |
|---|---|
| Collection of related web pages. | An individual document. |
| Contains multiple pages. | Represents a single page. |
| Usually associated with a domain name. | Accessible through a specific URL. |

### How Do We Access Websites?

Websites are accessed through URLs (Uniform Resource Locators) using web browsers.

Examples of web browsers:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari
- Opera

## 2. Understanding the Internet and World Wide Web

Before learning website designing, it is important to understand the Internet and the World Wide Web.

### What is the Internet?

The Internet is a worldwide network of interconnected computer networks that communicate with each other.

It allows computers and other devices to exchange information and communicate globally.

Examples of Internet services include:

- World Wide Web
- Email
- File Transfer
- Online Communication
- Video Conferencing

### What is the World Wide Web (WWW)?

The World Wide Web is an information system that operates over the Internet.

It allows users to access interconnected documents, resources, and web pages through web browsers.

The WWW uses technologies and protocols such as:

- HTML – To structure web content.
- HTTP – To transfer web resources.
- HTTPS – Secure communication over HTTP.
- URLs – To identify and locate web resources.

**Important Difference:**

The Internet is the global network infrastructure, whereas the World Wide Web is a service that operates on top of the Internet.

## 3. History of the World Wide Web

The World Wide Web was invented by **Sir Tim Berners-Lee** while working at CERN (European Organization for Nuclear Research).

His goal was to make information sharing easier between researchers around the world.

### Important Historical Events

| Year | Event |
|---|---|
| 1989 | Tim Berners-Lee proposed the concept of the World Wide Web. |
| 1990 | He developed the first web browser, web server, and the foundations of the Web. |
| 1991 | The World Wide Web became publicly available. |
| 1993 | CERN made the Web technology available without royalties, helping its worldwide adoption. |
| 1994 | The World Wide Web Consortium (W3C) was founded. |
| 2014 | HTML5 became a W3C Recommendation. |

### Who Invented HTML?

HTML (HyperText Markup Language) was created by Tim Berners-Lee around 1991 as one of the fundamental technologies of the World Wide Web.

HTML provides a standard way to structure documents that can be displayed in web browsers.

### What is W3C?

W3C stands for **World Wide Web Consortium**.

It is an international organization founded in 1994 by Tim Berners-Lee.

Its purpose is to develop and promote standards and guidelines that help ensure the long-term growth and interoperability of the Web.

Examples of technologies associated with Web standards include:

- HTML
- CSS
- Accessibility Guidelines
- Web APIs and other Web technologies

**Why are Web Standards Important?**

Web standards help ensure that:

1. Websites work consistently across different browsers.
2. Developers follow common technical guidelines.
3. Websites remain accessible to different users.
4. Web technologies can work together.
5. Websites are easier to maintain and develop.

**Note:** HTML5 is an important version of HTML, but modern HTML development follows the continuously maintained HTML Living Standard published by WHATWG.

## 3.1 Introduction to SGML

### What is SGML?

SGML stands for **Standard Generalized Markup Language**.

It is an international standard (ISO 8879) developed to define the structure and organization of documents using markup.

SGML provides rules for defining markup languages that describe different types of documents.

It was mainly designed for managing large and complex documents, especially in publishing and documentation systems.

### What is the Relationship Between SGML and HTML?

HTML was originally developed using SGML as its foundation.

Tim Berners-Lee developed HTML as a simplified markup language for creating and sharing documents over the World Wide Web.

HTML adopted several concepts from SGML, including:

- Elements and tags.
- Attributes.
- Document structure.
- Markup rules.
- Document Type Definitions (DTDs).

### SGML vs HTML

| SGML | HTML |
|---|---|
| Standard Generalized Markup Language. | HyperText Markup Language. |
| A standard for defining markup languages. | A markup language used to structure web pages. |
| Used for describing and managing structured documents. | Used to create web documents. |
| More complex and flexible. | More specific and easier to use for web documents. |
| Can define different markup languages. | Defines predefined elements and attributes for HTML documents. |

### HTML, SGML, and XML

HTML, SGML, and XML are related markup technologies, but they serve different purposes.

- **SGML:** A standard for defining markup languages.
- **HTML:** A markup language designed for structuring web documents.
- **XML:** Extensible Markup Language, designed to store and transport structured data.

**Important Historical Note:**

Early HTML was an SGML application. HTML5, however, is no longer defined using SGML syntax. Modern HTML uses its own parsing rules and document structure.

### Understanding the Relationship

Think of SGML as a standard that provides a framework for defining markup languages, while HTML is a specific markup language developed for the Web.

This relationship helps us understand the historical foundation of HTML.

## 4. Evolution of the Web

The Web has evolved significantly over time. Its development is commonly described through different generations.

### Web 1.0 – Read Only Web

Web 1.0 represents the early stage of the Web.

Characteristics:

- Mostly static web pages.
- Users could mainly read information.
- Very limited user interaction.
- Content was generally published by website owners.
- Websites were built using basic HTML.

Example: An old-style company website displaying company information without interactive features.

### Web 2.0 – Read and Write Web

Web 2.0 introduced greater interaction and user-generated content.

Characteristics:

- Users can create and share content.
- Social networking platforms.
- Comments and discussions.
- Interactive web applications.
- Dynamic content.

Examples:
- Facebook
- YouTube
- Instagram
- Wikipedia

### Web 3.0 – Semantic and Decentralized Web

Web 3.0 is commonly associated with ideas such as decentralization, semantic technologies, and greater user control over digital assets and identity.

Characteristics and associated concepts:

- Decentralized applications.
- Blockchain technology.
- Smart contracts.
- Semantic data and machine-readable information.
- AI-assisted and intelligent web experiences.

**Important:** Web 3.0 is an evolving concept, not a single finalized version of the Web.

## 5. Introduction to Website Designing and Development

Website designing and website development are closely related, but they have different responsibilities.

### Frontend – Website Designing

Frontend refers to the part of a website that users can see and interact with.

It focuses on:

- Layout and structure.
- Colors and typography.
- Navigation menus.
- Buttons and forms.
- Images and visual elements.
- User interaction.

Technologies used in frontend development:

| Technology | Purpose |
|---|---|
| HTML | Structures website content. |
| CSS | Styles and designs website elements. |
| JavaScript | Adds interactivity and dynamic functionality. |
| Bootstrap | CSS framework for responsive layouts and components. |
| jQuery | JavaScript library that simplifies common JavaScript tasks. |

### Backend – Website Development

Backend refers to the server-side functionality of a website or web application.

It focuses on:

- Business logic.
- Database operations.
- User authentication.
- Data processing.
- Server-side operations.
- APIs and integrations.

Examples of backend technologies:

- PHP
- Python
- Java
- Node.js
- ASP.NET Core

Databases:

- MySQL
- MongoDB
- Microsoft SQL Server
- PostgreSQL

**Example: Login System**

When a user enters their email and password:

1. Frontend displays the login form.
2. JavaScript can validate the input.
3. Backend receives the submitted credentials.
4. Backend verifies the credentials against stored user information.
5. The application returns an appropriate response.

# 7. Introduction to HTML

## What is HTML?

HTML stands for **HyperText Markup Language**.

It is the standard markup language used to create and structure content on web pages.

HTML tells the browser how different elements of a web page are organized.

Examples of HTML content:

- Headings
- Paragraphs
- Images
- Links
- Lists
- Tables
- Forms

### Why is HTML Important?

HTML provides the basic structure of every web page.

Without HTML, browsers would not have the standard document structure needed to organize web content.

### Is HTML a Programming Language?

No. HTML is a markup language, not a programming language.

A programming language provides instructions and logic that can perform computations and operations.

HTML uses predefined tags and elements to describe the structure and meaning of content.

### Current HTML Version

HTML5 is the major modern version commonly taught in web designing courses.

It introduced many useful features, including:

- Semantic elements.
- Audio and video support.
- Improved form controls.
- Canvas element.
- Better document structure.

Modern HTML is maintained as a Living Standard by WHATWG.

### HTML File Extension

HTML files commonly use the following extensions:

- `.html`
- `.htm`

Example:

`index.html`

# 8. How HTML Works

HTML documents are written using elements.

A web browser reads the HTML document, interprets its structure, and renders the content on the screen.

### HTML Working Pattern

HTML documents follow a hierarchical, tree-like structure called the **DOM (Document Object Model)**.

Elements can contain other elements, creating parent-child relationships.

Example:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to My Website</h1>

    <p>This is my first web page.</p>
</body>
</html>
```

In this example:

- `html` is the root element.
- `head` contains document metadata.
- `title` defines the browser tab title.
- `body` contains the visible page content.
- `h1` represents a main heading.
- `p` represents a paragraph.

### What is an HTML Tag?

A tag is a markup instruction written inside angle brackets.

Examples:

```html
<h1>
<p>
<div>
<img>
```

HTML tags are used to define elements and their structure.

### What is an HTML Element?

An HTML element generally consists of:

1. Opening Tag
2. Content
3. Closing Tag

Example:

```html
<h1>Aptech Gulshan 2</h1>
```

Explanation:

- `<h1>` – Opening tag.
- `Aptech Gulshan 2` – Content.
- `</h1>` – Closing tag.

The complete structure is called an HTML element.

**Important:** Not every HTML element has a closing tag. Some elements are void elements.

Examples:

```html
<img src="image.jpg" alt="Sample Image">

<br>

<hr>

<input type="text">
```

### What are HTML Attributes?

Attributes provide additional information or configuration to an HTML element.

They are generally written inside the opening tag.

Example:

```html
<h1 class="heading">Aptech Gulshan 2</h1>
```

Explanation:

- `h1` – HTML tag.
- `class` – Attribute name.
- `heading` – Attribute value.
- `Aptech Gulshan 2` – Element content.

More examples:

```html
<img src="logo.png" alt="Company Logo">

<a href="https://www.google.com">Google</a>

<input type="text" placeholder="Enter your name">
```

In these examples:

- `src` specifies an image source.
- `alt` provides alternative text.
- `href` specifies a hyperlink destination.
- `type` specifies the input type.
- `placeholder` displays a hint inside an input field.

# 9. Types of HTML Elements

HTML elements can be categorized in different ways.

One important classification is based on their meaning.

### 1. Semantic Elements

Semantic elements clearly describe the meaning and purpose of their content.

Examples:

```html
<header></header>

<nav></nav>

<main></main>

<section></section>

<article></article>

<footer></footer>
```

Common semantic elements:

| Element | Purpose |
|---|---|
| `<header>` | Represents introductory content or a header. |
| `<nav>` | Contains navigation links. |
| `<main>` | Represents the main content of a page. |
| `<section>` | Represents a thematic section. |
| `<article>` | Represents independent, self-contained content. |
| `<aside>` | Represents related or supplementary content. |
| `<footer>` | Represents footer information. |

### 2. Non-Semantic Elements

Non-semantic elements do not describe the specific meaning of their content.

They are generally used as containers for grouping content and applying styling or layout.

Examples:

```html
<div></div>

<span></span>
```

Difference:

| `<div>` | `<span>` |
|---|---|
| Block-level element by default. | Inline element by default. |
| Used to group larger sections. | Used to group small portions of inline content. |
| Commonly used as a layout container. | Commonly used for styling text or inline content. |

**Important:** `<div>` and `<span>` are both non-semantic elements. They are not examples of semantic and non-semantic elements respectively.

# 11. Setting Up the HTML Development Environment

In this lecture, we use Visual Studio Code to create and run our first HTML document.

### Step 1 – Create a New Folder

Create a new folder anywhere on your computer.

Example:

`WebsiteDesigning`

This folder will contain all the files related to your website designing practice.

### Step 2 – Open the Folder in Visual Studio Code

1. Open Visual Studio Code.
2. Select **File** from the menu.
3. Click **Open Folder**.
4. Locate your `WebsiteDesigning` folder.
5. Select the folder and click Open.

You can also right-click the folder and select **Open with Code**, if the option is available.

### Step 3 – Create a New HTML File

Inside Visual Studio Code:

1. Locate the Explorer panel.
2. Click the New File icon.
3. Create a file named:

`index.html`

**Note:** The `.html` extension tells the system and development tools that the file contains HTML markup.

### Step 4 – Create the HTML Boilerplate

A boilerplate is a basic predefined structure that is used as the starting point for an HTML document.

Visual Studio Code supports Emmet, which helps developers generate HTML structures quickly.

To generate the HTML boilerplate:

1. Open your `index.html` file.
2. Type `!`
3. Press Enter or Tab.

You will get a basic HTML structure similar to this:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>
```

### Understanding the HTML Boilerplate

| Element / Declaration | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares that the document uses modern HTML. |
| `<html>` | Root element of the HTML document. |
| `lang="en"` | Specifies the document language as English. |
| `<head>` | Contains document metadata and linked resources. |
| `<meta charset="UTF-8">` | Defines character encoding. |
| `<meta name="viewport">` | Helps control the page layout on different screen sizes. |
| `<title>` | Defines the title displayed in the browser tab. |
| `<body>` | Contains the visible content of the web page. |

### Step 5 – Start Writing HTML Code

The `<body>` element is our primary working area for adding visible website content.

Example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>

    <h1>Welcome to Website Designing</h1>

    <p>My first HTML web page.</p>

</body>
</html>
```

### Step 6 – Run Your HTML File

There are different ways to view an HTML file in a browser.

**Method 1 – Open Directly in Browser**

1. Save your HTML file.
2. Open the folder where your file is saved.
3. Double-click `index.html`.
4. Your default web browser will open the page.

**Method 2 – Using Live Server Extension**

1. Open the Extensions panel in VS Code.
2. Search for Live Server.
3. Install the extension.
4. Open your HTML file.
5. Right-click inside the editor.
6. Select **Open with Live Server**.

Your website will open in a browser, usually using a local development address such as:

`http://127.0.0.1:5500/index.html`

Live Server automatically refreshes the browser when you save changes.

**Important:** F5 is normally associated with starting a debugging session in VS Code. It does not automatically open every HTML file in a browser unless the appropriate debugging configuration is available.

# 12. Introduction to URL

## What is a URL?

URL stands for **Uniform Resource Locator**.

A URL is the address used to locate a resource on the World Wide Web.

Resources may include:

- Web pages.
- Images.
- Videos.
- Documents.
- Other web resources.

Example:

`https://www.example.com/about.html`

### Why Do We Use URLs?

URLs allow browsers to locate and request specific resources from web servers.

Whenever we want to access a particular web page, we generally use its URL.

### Structure of a URL

Example:

`https://www.example.com/products/mobile.html?id=10`

| Component | Value | Purpose |
|---|---|---|
| Scheme / Protocol | `https` | Defines the communication protocol. |
| Subdomain | `www` | A subdomain of the main domain. |
| Domain Name | `example.com` | Identifies the website's domain. |
| Path | `/products/mobile.html` | Identifies a particular resource or route. |
| Query String | `?id=10` | Passes additional parameters. |

### Common URL Protocols

- HTTP – HyperText Transfer Protocol.
- HTTPS – HyperText Transfer Protocol Secure.

HTTPS provides encrypted communication between the browser and server using TLS.

### URL vs Domain Name

A domain name is only one part of a URL.

For example:

`https://www.google.com/search?q=html`

- Full URL: `https://www.google.com/search?q=html`
- Domain name: `google.com`
